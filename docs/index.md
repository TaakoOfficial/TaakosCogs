## Popular starting points

| Need | Suggested cogs |
| --- | --- |
| Moderation and server operations | `yalc`, `rolemanager`, `toolz`, `opsroom`, `accessreview` |
| Member support | `tickethub`, `forumflow`, `applications`, `suggestionbox` |
| Community programs | `eventcheckin`, `staffops`, `sponsorsync`, `communitydigest` |
| Roleplay and games | `fable`, `deepdelve`, `randomweather`, `rpcalander`, `spinwheel` |
| Privacy and reliability | `datasteward`, `linksentinel`, `communitypulse`, `cfxstatus` |

!!! tip "Commands"
    Documentation uses `[p]` as Red's configured prefix. Slash-capable commands are also available through Discord's `/` command picker.
